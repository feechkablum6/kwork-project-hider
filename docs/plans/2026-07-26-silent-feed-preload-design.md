# Тихая сборка единой ленты Kwork

## Задача

Пользователь должен сразу видеть уже доступные проекты и не наблюдать последовательные статусы загрузки, переходы по страницам или многократные перерисовки. Все доступные страницы Kwork по-прежнему должны объединяться, чтобы скрытые проекты не оставляли разреженную ленту.

## Выбранное поведение

- Первая страница остаётся на экране без отдельного индикатора расширения.
- Расширение в основном мире страницы получает остальные страницы в фоне с ограниченной параллельностью.
- Сборка запускается отдельным событием без штатного клика по пагинации и без прелоадера Kwork.
- После готовности данных Kwork получает один итоговый ответ с объединёнными проектами и перерисовывает ленту один раз.
- Пагинация скрыта во время успешной тихой сборки.
- При ошибке фоновой сборки расширение возвращает штатную пагинацию Kwork без бесконечных повторов.
- Фильтры, сортировка, кнопки карточек и постоянное скрытие проектов сохраняют прежнее поведение.

## Поток данных

Изолированный content script отправляет событие тихого запуска после появления первой страницы. MAIN-world перехватчик собирает параметры из текущего URL, получает первую страницу, узнаёт реальное количество страниц, затем загружает остальные порции с ограничением числа одновременных запросов. Ответы хранятся по номеру страницы, поэтому итоговая лента сохраняет исходный порядок и удаляет дубликаты.

Штатные запросы Kwork больше не удерживаются на время фоновой сборки. После готовности всех страниц выполняется один короткий штатный переход для итоговой отрисовки; его ответ дополняется собранными страницами, а прелоадер скрывается только на время этого запроса. Устаревшие ответы от предыдущего фильтра не смешиваются с новой лентой.

## Ошибки и границы

Если хотя бы одна страница недоступна или имеет неожиданный формат, расширение не показывает частично собранную ленту как полную. Оно пропускает штатный ответ Kwork и возвращает обычные номера страниц. Тайм-ауты ограничивают каждый фоновый запрос; повторного автоматического цикла нет.

## Проверка

Автоматические тесты подтверждают, что сборка запускается без штатного клика, запросы Kwork не блокируются, все страницы сохраняют порядок, не смешиваются между фильтрами и безопасно откатываются к штатной пагинации при ошибке. Живой сценарий проверяется в Chrome с большим числом скрытых карточек: прелоадер не появляется после первой порции, URL не проходит последовательно все страницы, а лента обновляется один раз.
