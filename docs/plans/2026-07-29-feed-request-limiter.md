# Ограничение фоновых запросов ленты Kwork

> **Для агентной реализации:** выполнять по TDD прямо в текущем checkout. Git worktree и коммит без отдельной просьбы пользователя не создавать.

**Цель:** убрать зависания Kwork при быстрых переключениях, не задерживая штатные действия пользователя.

**Архитектура:** штатный запрос Kwork уходит сразу. Расширение запускает свою фоновую сборку только после одной секунды без новых фильтров, отменяет запросы устаревшего набора и возвращает обычную пагинацию, если результатов слишком много для безопасной единой ленты.

**Стек:** Chrome Extension Manifest V3, JavaScript без зависимостей, XMLHttpRequest, Node.js `node --test`.

## Общие ограничения

- Не обходить серверные ограничения и не маскировать автоматические запросы.
- Не блокировать клики и переходы пользователя.
- Не собирать в один DOM более десяти страниц Kwork.
- При ограничении или ошибке оставлять штатную пагинацию доступной.
- Сохранять двухслойную схему MAIN world / isolated world.
