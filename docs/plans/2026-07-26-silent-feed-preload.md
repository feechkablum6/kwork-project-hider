# Silent Feed Preload Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Заменить последовательное листание Kwork на тихую фоновую сборку всех страниц с одной итоговой перерисовкой ленты.

**Architecture:** Isolated content script запускает MAIN-world сборщик отдельным событием. Сборщик получает параметры из текущего URL, загружает страницы с ограниченной параллельностью и хранит их по номеру, не удерживая штатные запросы Kwork. После готовности выполняется один короткий итоговый запрос; его прелоадер скрыт, а ответ получает объединённую ленту.

**Tech Stack:** Chrome Extension Manifest V3, JavaScript без зависимостей, XMLHttpRequest, Node.js `node --test`.
